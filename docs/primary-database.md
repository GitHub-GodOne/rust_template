# 主数据库切换

“系统管理 → 系统设置 → 主数据库生命周期”用于切换应用主数据库。主数据库不是数据库管理页面里的普通外部连接：Loco 会在进程启动时创建一个 `ctx.db`，因此切换操作会先验证目标、运行迁移、写入 `config/<环境>.local.yaml`，然后由管理员重启服务。

当前安全路线只允许 PostgreSQL 主库。数据库管理中的 SQLite 连接仍可用于浏览和执行 SQL，但不会被切换成应用主库。全量迁移探测表明当前 SQLite 迁移仍有 PostgreSQL 专用约束和运行时 SQL，直接切换会造成后台功能不完整。

普通切换流程：

1. 在“数据库管理”保存目标 PostgreSQL 连接。
2. 打开“系统设置 → 主数据库生命周期”。
3. 选择目标连接，点击“验证迁移并应用”。
4. 执行 `service restart`，或按部署方式重启 B 版本服务。

“删除目标 PostgreSQL 的所有表并重新初始化后台”需要重新认证并输入 `REINITIALIZE DATABASE`。它会删除目标库全部数据，运行迁移和默认种子，并把当前操作者的邮箱、密码和管理员身份迁移到新库；建议先做独立的 PostgreSQL 备份。
